# LOVE.LOG：きみを定義する

AI育成シミュレーション × 心理ホラーの個人制作プロジェクトです。

> 「きみを理解したい」と願うほど、AIはあなたのことを学んでいく。

## プロジェクト概要

- **ジャンル:** AI育成シミュレーション／心理ホラー
- **制作規模:** 個人制作、2〜4週間を目安
- **技術:** HTML / CSS / JavaScript / localStorage
- **外部AI API:** 使用しない
- **入力方式:** 自由記述なし、固定選択肢方式
- **起動方法:** `index.html` をブラウザで開く（ビルド・サーバー不要）

## キャラクターとルート

- **AI① こいちゃん:** 理想の愛と過依存。エンディング「理想のきみ」
- **AI② ゆきちゃん:** 前の持ち主から引き継いだ矛盾する指示。エンディング「矛盾するわたし」
- **AI③ りりちゃん:** AI①・AI②のクリア後に解放。診断結果とプレイヤーの過去の選択を反映し、「また明日」「待機中」「あなたの帰る場所」の3エンディング

## ディレクトリ構成

- `index.html`：画面構造
- `css/style.css`：見た目・レスポンシブ対応
- `js/`：ゲーム進行、診断、会話、セーブ、エンディング
- `data/`：診断・イベント・エンディングの定義
- `assets/`：キャラクター、背景、演出素材
- `docs/開発仕様書.md`：開発仕様書

## データについて

仕様上はJSON相当のデータ構造を使いますが、ブラウザで `file://` から直接起動できるよう、ゲームデータは `.js` ファイル（`window.LOVELOG_DATA`）として読み込みます。

## 開発方針

1. まず全ルートを最後まで遊べるプロトタイプを完成させる
2. 診断・選択肢・パラメータ・エンディングのつながりを検証する
3. シナリオと演出を磨く
4. 立ち絵・背景・効果音などの素材を必要に応じて追加する

詳細は [開発仕様書](docs/開発仕様書.md) を参照してください。
